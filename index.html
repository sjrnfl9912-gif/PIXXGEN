📝 3. 이력카드 입력하기 — 「이력 필요」 탭

옛 재고(2023~2025년 제작분)는 출하될 때 디텍터 S/N이 정해져, 출하 후 생산이력을 새로 적어야 합니다. 이력카드는 무작위로 오므로 S/N으로 찾아 입력합니다.

1

S/N 검색 (실시간 + 진단)

이력카드의 TFT S/N 또는 디텍터 S/N을 상단 입력창에 타이핑/붙여넣기 하면 실시간으로 아래 목록이 좁혀지고, 진단 바가 4분할 카드로 상태를 보여줍니다 — 생산기록 / 출하완료 폴더 / 검사포장 / 종합. 어디에도 없는 S/N(오기입)도 즉시 알 수 있습니다. Enter로 큐에 추가.

🔍
QJ415092KAAA ← 입력 즉시 목록 필터링
2

작업 큐에 쌓기

입력한 카드가 큐에 칩으로 쌓입니다. 각 칩에 품명 · 디텍터 · TFT가 같이 표시되어 확인이 쉽습니다. 여러 장 먼저 입력해두고 한 번에 작성해도 됩니다.

PRUDENT·K120260A1·QJ415092PIXX·P330260E1·CJ519121
3

생산이력 입력

큐 칩을 클릭하면 폼이 열립니다. TFT S/N·작업자·제작완료일이 자동 프리필됩니다 (작업자는 화면 좌측에서 선택한 사람, 완료일은 오늘). Tab으로 칸 이동.

생산번호
TFT S/N
작업자
완료일
4

저장 → 잘못 적었으면 다시 수정

저장 버튼 한 번이면 생산관리대장에 추가되고 자동으로 다음 카드로 넘어갑니다. 잘못 입력한 경우 완료된(✓) 칩을 다시 클릭하면 「수정 모드」로 폼이 다시 열려 고칠 수 있습니다.

💾 저장하고 다음 ✏ 수정 저장

💾 5. 저장 — 가장 중요
⚠️ 입력·수정해도 자동 저장되지 않습니다. 반드시 우측 상단 💾 저장 버튼(또는 Ctrl+S)을 눌러야 서버에 반영됩니다.
  • 저장 전에는 빨간 「저장 안 됨」 표시가 뜹니다.
  • 저장 안 하고 페이지를 닫으면 경고가 나옵니다.
  • 저장하면 다른 사람 화면에도 실시간 반영됩니다.
  • 같은 S/N이 중복되면 「중복 S/N」으로 빨갛게 표시됩니다.
※ 「이력 필요」 탭의 [저장하고 다음]은 누르는 즉시 저장됩니다 (별도 저장 불필요).

🤖 7. 자동화 스크립트 (관리자용)

회사 PC에서 PowerShell 스크립트가 작업 스케줄러로 매일 자동 실행됩니다.

  • 매일 17:00 — 통합 출하 이력 엑셀 → 검사포장(DB) 업로드
  • 매일 17:10 — 출하완료 폴더 → TFT 매칭(DB) 동기화
  • 매일 17:30 — DB(검사포장·생산·TFT 매칭) + 통합취합본 → 서버 공유폴더로 백업
📁 스크립트 위치 (공용 서버 — 누구나 열람 가능)
\\SERVER03\Fab_Sync\99. 기타 - 팀원 임시 폴더\홍승범\PIXXGEN\PIXXGEN-sync\
※ 폴더 안 README.txt 에 설치·작업 스케줄러 등록 방법이 정리돼 있습니다.
💡 다른 PC에서도 백업 가능 위 공용 서버의 PIXXGEN-sync 폴더를 다른 PC에 복사하고 작업 스케줄러에 등록하면, 그 PC에서도 백업·동기화가 됩니다. 스크립트가 특정 PC 경로에 묶여 있지 않아 복사만 하면 바로 동작합니다 — 회사 PC가 꺼져 있어도 다른 PC로 백업을 이어갈 수 있습니다.
