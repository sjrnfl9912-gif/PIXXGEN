📖 사용 설명서

화면 구성

  • 검사포장 출하이력 — 회사 엑셀에서 자동으로 들어옵니다. 직접 입력하지 않습니다.
  • 생산관리대장 — 생산 담당자가 직접 작성하는 탭입니다.
  • TFT 매칭 — 출하완료 폴더에서 자동 수집됩니다. (보기 전용)
  • 통합취합본 — 🔄 출하+생산 취합 버튼으로 두 데이터를 합쳐서 봅니다.
  • 📊 KPI 통계 — 생산 실적이 작업자별·월별로 자동 집계됩니다.

⚠️ 저장 — 가장 중요

입력·수정해도 자동 저장되지 않습니다. 반드시 우측 상단 💾 저장 (또는 Ctrl+S) 을 눌러야 서버에 반영됩니다.
  • 저장 전에는 빨간 저장 안 됨 표시가 뜨고, 페이지를 닫으면 경고가 나옵니다.
  • 저장하면 다른 사람 화면에도 실시간으로 반영됩니다.
  • 같은 S/N이 중복되면 중복 S/N으로 빨갛게 표시됩니다.

백업

  • 자동 백업 — 회사 PC에서 매일 오후 5시 30분에 자동으로 백업됩니다. (회사 PC가 켜져 있을 때 실행)
  • 📥 백업 버튼 — 지금 즉시 데이터를 JSON 파일로 내려받습니다.
  • 📤 복원 버튼 — 백업 파일로 데이터를 되돌립니다.
  • 데이터 원본은 서버에 보관됩니다. 중요한 작업 전후엔 📥 백업을 직접 눌러 파일도 따로 받아두면 더 안전합니다.
